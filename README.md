# 🇹🇭 Thailand Trip Hub

**Live site: [manangupta.github.io/thailand-trip-hub](https://manangupta.github.io/thailand-trip-hub/)**

Personal trip planning hub for Bangkok · Pattaya · Phuket, 28 Aug – 10 Sep 2026.

Single-file HTML app (`index.html`) — no build step, no dependencies. Deployed via GitHub Pages, synced from the same conversation that maintains the itinerary.

## What's in it

- **Overview** — trip summary, latest changes
- **Day-by-Day** — full 14-day itinerary with cost estimates and transport info for every stop
- **Hotels** — booking tracker for all 7 stays
- **Phi Phi / Islands** — weather contingency plan, alternative island tours
- **Places Checklist** — every attraction with cost, booking requirement, and priority (P1–P3)
- **Birthday Dinners** — reservation details for both birthdays
- **Booking Checklist** — prioritized list of what still needs booking
- **Pre-Flight Prep** — visa, currency, documentation
- **Packing** — checklist
- **💰 Expenses** — actual spend tracker
- **🧾 Expected Budget** — rough advance cost estimate by category

Includes dark mode and a lightweight client-side login gate (not real security — just keeps this off search engines and casual visitors, since the repo is public).

## Updating

Whenever the itinerary changes, the updated `index.html` gets pushed here and GitHub Pages redeploys automatically within ~30–60 seconds.
